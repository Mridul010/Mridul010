## `> cron "0 0 * * *" update_activity`

> 🤖 **[LIVE — Auto-updates every 24h via GitHub Actions]**

<!--RECENT_ACTIVITY:start-->
```
Fetching latest commits... this section updates automatically.
Set up the workflow below to make it live.
```
<!--RECENT_ACTIVITY:end-->

<details>
<summary><code>⚙️ Enable live activity updates — GitHub Actions setup</code></summary>

<br/>

Create `.github/workflows/update-activity.yml`:

```yaml
name: Update README Activity

on:
  schedule:
    - cron: "0 0 * * *"   # Runs daily at midnight UTC
  workflow_dispatch:

jobs:
  update-activity:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: Readme-Workflows/recent-activity@v2.4.0
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        with:
          MAX_LINES: 6
          COMMIT_MSG: "chore(readme): auto-update recent activity [skip ci]"
```

Once added, your last 6 GitHub events (pushes, PRs, issues, reviews) will live-update every day — keeping your README breathing.

</details>

<details>
<summary><code>⚙️ Enable the contribution snake — GitHub Actions setup</code></summary>

<br/>

Create `.github/workflows/snake.yml`:

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 12 * * *"
  workflow_dispatch:

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v3
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
